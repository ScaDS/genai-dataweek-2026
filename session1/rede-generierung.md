# Text-Generierung

In dieser Übung wollen wir eine Rede generieren. Ein Beispiel-Prompt ist in [diesem Dokument verfügbar](./rede-prompt.docx). 

Nutzen Sie eine KI-Chat-App Ihrer Wahl und idealerweise nicht die gleiche wie Ihr Platznachbar, um vergleichen zu können:
* [Lumo](https://lumo.proton.me/) (Kommerzieller Anbieter, spezialisiert auf Privatsphäre-Aspekte)
* [OpenAI / ChatGPT](https://chatgpt.com/) (Kommerzieller Anbieter)
* [Anthropic / Claude](https://claude.ai/) (Kommerzieller Anbieter)
* [Google Gemini](https://gemini.google.com/) (Kommerzieller Anbieter)
* [Helmholtz Blablador](https://helmholtz-blablador.fz-juelich.de/) (akademischer Anbieter)
* [GWDG / Chat AI / Kisski der Academic Cloud](https://chat-ai.academiccloud.de/) (akademischer Anbieter)

Wenn eine erste Rede generiert wurde, generieren Sie eine zweite. Modifizieren Sie:
* Rahmen der Rede (Interne Senatssitzung anstatt öffentlicher Rede)
* Zielgruppe (beispielsweise Professorinnen und Professoren anstatt Studierende und Journalisten)
* Länge der Rede
* Details des Inhalts

Hinweis: Limitieren Sie die Zeit, die Sie hierfür benutzen. Es folgen andere spannende Übungen.
