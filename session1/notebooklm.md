# Videoübersichten über wissenschaftliche Arbeiten

In dieser Übung werden wir eine Videoübersicht über eine wissenschaftliche Publikation erstellen. Dafür benötigen Sie einen Google-Account.

⦁ Melden Sie sich bei [NotebookLM](https://notebooklm.google/) an

⦁ Laden Sie ein Dokument das Sie gut kennen, eine eigene aktuelle Publikation oder eine kürzlich gelesene Arbeit hoch. Achten Sie dabei auf das Urheberrecht. Wenn die Veröffentlichung beispielsweise unter einer CC-BY 4.0-Lizenz veröffentlicht wurde, dürfen Sie dies völlig legal tun.
